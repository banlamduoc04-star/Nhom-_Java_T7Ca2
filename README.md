📖 Giới thiệu
OISM là hệ thống hướng đến việc quản lý sản phẩm, hàng hóa, tồn kho và đơn hàng tập trung.
🛠️ Công nghệ sử dụng:
Java
Spring Boot
Spring Data JPA
Maven
H2 Database
✨ Chức năng chính: 
Quản lý người dùng và đăng nhập
Quản lý sản phẩm và danh mục
Quản lý tồn kho
Quản lý nhập hàng và chuyển kho
Quản lý đơn hàng
